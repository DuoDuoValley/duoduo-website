多多谷玩家工具｜V4 獨立測試版

使用方式：
1. 解壓縮整個 ZIP。
2. 開啟 duoduo_player_tools_v4 資料夾。
3. 使用 Chrome / Edge 開啟 index.html。

V4 功能：
- 裝備強化：基礎、卓越、極限；單次／強化至目標；幸運石 0–6 顆。
- 貨幣圖示：楓幣、楓葉點數；裝備強化費用依指定規則試算。
- 特殊強化：圖騰強化（輪迴碑石、彩虹月石寶石圖騰、小筱精靈圖騰）、內襯強化、阿斯特拉（基礎／卓越／極限）。
- 抽獎模擬：保留 V3 原有獎池、單抽／十連／百連、機率表、搜尋及抽數統計。
- 模擬完全在瀏覽器本機執行，不連線遊戲伺服器，也不會修改遊戲帳號或道具。

資料與規則：
- 裝備強化、抽獎池資料沿用 V3 所使用的「強化模擬與抽獎模擬.xlsx」。
- 圖騰、內襯、阿斯特拉的階段屬性、機率與材料需求取自「強化模擬與抽獎模擬2.xlsx」。
- 裝備強化費用：基礎 700 萬楓幣 × 強化階段倍率、500 楓葉點數；卓越 1,800 萬 × 階段倍率、800 楓葉點數；極限 3,000 萬 × 階段倍率、1,200 楓葉點數。楓葉點數按每次嘗試固定消耗。
- 圖騰／內襯楓幣消耗使用 Excel 的 E 欄／E 百萬楓幣標示換算；阿斯特拉 Excel 未列楓幣費用，因此不自行添加。
- 幸運石每顆加 5 個百分點，最多 6 顆，最終成功率最高 100%；失敗不降級但會消耗材料與貨幣。
- 抽獎保留 Excel 表列機率，不將機率合計強制調整為 100%；模擬按表列機率相對權重抽取。
- 內襯部位名稱目前以常見六個部位作為選單標籤；若正式表格有更精確的部位名稱，可再替換。


V4.2 獎池管理：在「抽獎模擬器」展開「獎池管理（管理員）」可修改獎池名稱、圖示路徑、道具名稱與表列機率，並可新增/刪除道具。設定儲存於目前瀏覽器 localStorage；可匯出 JSON 備份或匯入 JSON 到其他瀏覽器。還原初始獎池可清除本機修改。抽獎介面不再顯示「表列機率合計」。


V4.3 介面與圖片管理：
- 裝備強化下拉選單顯示「基礎／卓越／極限」，內部計算識別碼不變。
- 圖片管理原型請在同一份 index.html 網址後加上 #admin-images（index.html#admin-images）進入；玩家前台導覽列不會顯示管理入口。
- 可逐項上傳／替換分類、圖騰、內襯、阿斯特拉目標圖片，並可匯出／匯入 JSON 備份。
- 目前為獨立測試版本機儲存，未連接正式官網後台或雲端資料庫；正式上線時須再整合登入權限與伺服器儲存。
